# 综合练习与项目

看懂了 ≠ 会做。这里是一条由易到难的项目路线，每个项目都综合运用前面多节的知识。**做完这五个项目，HTML 和 CSS 就真正属于你了。**

## 通用要求（每个项目都适用）

- [ ] 语义化标签，每页一个 `h1`，标题不跳级
- [ ] 所有图片有 `alt`，所有输入框有关联 `label`
- [ ] 全局 `box-sizing: border-box`
- [ ] 颜色、间距用 CSS 变量管理
- [ ] class 命名遵循 BEM 或至少“表达用途”
- [ ] 在 320px ~ 1400px 宽度范围内拖动无布局断裂、无横向滚动条
- [ ] 用 DevTools 自查一遍 Console 无报错、Network 无 404

## 项目一：个人名片页 ⭐

**综合**：HTML 骨架、文本、图片、盒模型、字体排版

一张居中的卡片：头像（圆形）、姓名、一句话介绍、几个社交链接。卡片有圆角、阴影、悬停微动效。

**验收点**：卡片在页面正中（水平+垂直）；头像用 `aspect-ratio: 1` + `border-radius: 50%` + `object-fit: cover`。

## 项目二：菜谱/文章详情页 ⭐⭐

**综合**：语义化、列表、图片、排版、居中容器

一篇图文并茂的长文：标题、封面图、配料用无序列表、步骤用有序列表、小贴士用引用块。正文容器 `max-width` 居中，行高舒适。

**验收点**：去掉 CSS 后文档结构依然清晰（语义化的试金石）；正文阅读体验好（对比 `line-height: 1` 感受差距）。

## 项目三：问卷报名表 ⭐⭐⭐

**综合**：表单全家桶、伪类、选择器

一份完整的活动报名表：文本、邮箱、单选、多选、下拉、多行文本、同意协议复选框、提交按钮。用 `fieldset` 分区，原生校验属性齐全。

**验收点**：点击任何文字标签都能聚焦对应输入框；`:focus` 状态清晰可见；试着用 `:has()` 实现“未勾选协议时提交按钮变灰”。

## 项目四：响应式课程列表页 ⭐⭐⭐⭐

**综合**：Flexbox、Grid、响应式、动效、现代 CSS

页面结构：吸顶导航栏（Flexbox）+ 英雄区（大标题用 `clamp()` 流式字号）+ 课程卡片墙（Grid `auto-fill`）+ 页脚。卡片：16:9 封面图、标题单行省略、简介多行截断、悬停上浮动效。

**验收点**：手机单列 → 桌面多列全程平滑；导航 `position: sticky` 吸顶；所有动效只用 `transform` 和 `opacity`。

## 项目五：仿写一个真实页面 ⭐⭐⭐⭐⭐

选一个你喜欢的真实网站（B 站首页头部、知乎问题页、Apple 产品页……）截取一屏，**像素级仿写**。允许用 DevTools 观察它的实现，不允许直接复制它的代码。

这是前端学习的成人礼：真实页面的复杂度会逼出你所有知识盲区。做完你会对“我会 CSS”这句话有全新的敬畏和底气。

## 每个项目的标准工作流

1. **先画结构**：纸上画出区块划分，标出语义标签——先想清楚再动手。
2. **HTML 先行**：完整写完结构，浏览器里确认内容无误，再写 CSS。
3. **由外到内**：先布局大框架（Grid/Flexbox），再修饰组件细节。
4. **移动优先**：从窄屏样式写起，逐级增强。
5. **AI 协作点**：卡住 20 分钟以上再问 AI，问的时候带上你的代码和已经排除的可能（参考[与 AI 一起学前端](/advanced/ai)）；做完让 AI Review，判断哪些建议值得采纳。
6. **自查清单**：过一遍本页开头的通用要求。

## 自我评估：你出师了吗

能全部答“是”，就可以自信地开始学 JavaScript 了：

- [ ] 不查资料能手写标准 HTML 骨架和一个语义化页面框架
- [ ] 能解释盒模型，并说清 `border-box` 解决了什么问题
- [ ] 给定两个选择器，能判断谁的优先级高
- [ ] 能徒手写出 Flexbox 水平垂直居中和“固定侧边栏 + 自适应主区”布局
- [ ] 能用 Grid 写出自适应卡片墙并解释 `minmax` 每个参数
- [ ] 页面出问题时，第一反应是打开 DevTools 而不是干瞪眼
- [ ] 能看出 AI 生成代码里至少三类常见问题

## 下一步

HTML/CSS 是静态的骨与皮，**JavaScript** 将赋予页面行为——点击、请求数据、动态渲染。学完 JS 基础，你就可以进入 **Vue 3** 的世界，用组件化的方式构建真正的 Web 应用。前面学的一切（语义化、盒模型、Flexbox、BEM、CSS 变量）都会在组件开发中天天见。

祝编码愉快。💪

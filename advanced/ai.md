# 与 AI 一起学前端

AI 已经能写出相当不错的 HTML 和 CSS——这是事实，回避它是自欺欺人。但结论不是“不用学前端了”，而是**你的学习方式和工作方式都会带上 AI**。这一节讲怎么带得好。

## 一个必须想明白的问题

> AI 能写代码，公司为什么还要雇你？

因为公司购买的从来不是“打字”，而是**责任**：需求变了要改、线上出 Bug 要修、AI 写的代码要有人判断对不对、能不能上线。这些判断全部依赖基础知识。

两条路摆在面前：

- **基础扎实的你 + AI**：AI 十秒生成页面，你三分钟审查出它的语义化问题和布局隐患，改完上线。你是 AI 的**指挥官**。
- **只会提示词的你 + AI**：AI 生成页面，你看不出问题，上线后布局在手机上崩了，你只能把报错原样贴回给 AI，祈祷它这次能修好。你是 AI 的**传声筒**——而传声筒是最容易被替换的。

**AI 是能力的放大器：基础 × AI = 产出。基础趋近于零时，乘出来还是零。**

## AI 在学习中的四种正确用法

### 1. 当 24 小时答疑老师

遇到不懂的概念随时问，追问到懂为止——这是传统课堂给不了的：

> “我不理解 CSS 的外边距合并，能用初学者能懂的方式解释一下，再给一个我能动手复现的最小例子吗？”

### 2. 当逐行讲解员

看到看不懂的代码（别人写的、DevTools 里扒的、AI 自己生成的）：

> “逐行解释这段 CSS 的作用，特别是 `flex: 1 1 280px` 这里的三个值分别控制什么。”

### 3. 当出题考官

学完一个主题，让 AI 检验你：

> “我刚学完 CSS 选择器优先级，出 5 道由易到难的判断题考我，先别给答案。”

### 4. 当代码审查对象（强烈推荐）

让 AI 生成代码，**你来挑毛病**：语义化了吗？命名合理吗？有没有用表格布局的老毛病？这个练习同时锻炼阅读能力和判断力——而且你会发现 AI 真的会犯错，这个发现本身就是免疫力。

::: danger 唯一的禁忌用法
让 AI 直接完成作业，原样上交。短期看你赚了两小时，长期看你在上机考核、面试手写环节里裸奔。作业不是要那个 HTML 文件，是要写它的过程在你脑子里留下的东西。
:::

## 提示词的质量取决于你的词汇量

对比这两个提示词：

> ❌ “帮我做一个好看的网页，有图片有文字。”

> ✅ “做一个课程卡片列表：语义化 HTML，Grid 布局，`repeat(auto-fill, minmax(240px, 1fr))` 自适应列数；卡片含 16:9 封面图（`object-fit: cover`）、标题（单行省略）、两行简介（多行截断）、价格；悬停时卡片上浮 4px 并加阴影，过渡 0.2s；移动优先，使用 BEM 命名和 CSS 变量管理主题色。”

第二个提示词里的每一个术语，都是本指南前面章节的内容。**你的前端词汇量，就是你的提示词上限**——这就是为什么“学提示词”绕不开“学前端”。

## 用 AI 调试的正确姿势

把 AI 当成结对调试的同事，而不是甩锅对象：

1. **先自己定位**：用 [DevTools](/advanced/devtools) 缩小范围——是哪个元素？哪条规则？
2. **给足上下文**：贴上相关代码 + 期望行为 + 实际行为 + 已排除的可能。“布局炸了帮我修”是最低效的提问。
3. **理解再采纳**：AI 给出修复后，问自己（或问它）“为什么这样就好了？”——说不出原因的修复，下次还会坏。
4. **验证**：改完亲眼确认，包括手机尺寸。AI 不会替你负责。

## 保持警惕的三件事

1. **AI 会一本正经地胡说**：编造不存在的属性、给出过时的写法。交叉验证渠道：MDN、caniuse。
2. **AI 的默认审美是平庸的**：它生成的界面像“所有网站的平均值”。审美和产品感，得你自己长。
3. **依赖是渐进的**：每周留一点“无 AI 时间”，从零手写一个小页面，像健身一样维持肌肉。

## 练习

1. 用“出题考官”模式，让 AI 就盒模型考你 5 道题，把答错的概念重学一遍。
2. 让 AI 生成一个注册表单页面，然后独立完成一次 Code Review：检查语义化、label 关联、命名规范、响应式，写出至少 5 条改进意见并动手改掉。
3. 拿一个你写过的练习，让 AI 提出改进建议，判断每条建议该采纳还是拒绝，并写出理由——**判断力，就是这样练出来的。**

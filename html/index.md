# 认识 HTML

HTML（HyperText Markup Language，超文本标记语言）不是编程语言，而是**标记语言**：它用一套“标签”给文本内容做标记，告诉浏览器“这是标题”“这是段落”“这是图片”。

## 标签、元素与属性

```html
<a href="https://www.example.com">访问示例网站</a>
```

这行代码里包含了三个核心概念：

- **标签（Tag）**：`<a>` 是开始标签，`</a>` 是结束标签。
- **元素（Element）**：从开始标签到结束标签的整体，包括中间的内容。
- **属性（Attribute）**：`href="https://www.example.com"` 写在开始标签里，为元素提供附加信息。属性名、等号、引号包裹的属性值。

有些元素没有内容，也就不需要结束标签，称为**空元素（自闭合元素）**：

```html
<img src="photo.jpg" alt="一张照片" />
<br />
<input type="text" />
```

::: tip
空元素结尾的斜杠 `/` 写不写都合法（`<br>` 和 `<br />` 等价）。团队里统一风格即可。
:::

## HTML 文档的骨架

每个 HTML 文件都应该有这样的结构：

```html
<!DOCTYPE html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>页面标题</title>
  </head>
  <body>
    <!-- 页面上可见的内容都写在这里 -->
  </body>
</html>
```

逐行解释：

| 代码 | 作用 |
| --- | --- |
| `<!DOCTYPE html>` | 文档类型声明，告诉浏览器“这是现代 HTML”，必须写在第一行 |
| `<html lang="zh-CN">` | 根元素，`lang` 声明页面语言，影响搜索引擎和读屏软件 |
| `<head>` | 页面的“元信息”区，内容不直接显示在页面上 |
| `<meta charset="UTF-8">` | 字符编码，不写可能出现中文乱码 |
| `<meta name="viewport" ...>` | 移动端适配的开关，详见[响应式设计](/concepts/responsive) |
| `<title>` | 浏览器标签页上显示的标题 |
| `<body>` | 所有可见内容的容器 |

::: warning 中文乱码？
如果页面中文显示成乱码，九成是缺了 `<meta charset="UTF-8">`，或者文件本身没有以 UTF-8 编码保存（VS Code 默认就是 UTF-8）。
:::

## 嵌套规则

元素可以嵌套，但必须**先开后合、完整包含**：

```html
<!-- ✅ 正确：p 完整地包住 strong -->
<p>这段话里有一个<strong>重点</strong>词。</p>

<!-- ❌ 错误：标签交叉了 -->
<p>这段话里有一个<strong>重点</p></strong>
```

浏览器对错误嵌套非常“宽容”——它不报错，而是自作主张地修复，结果往往不是你想要的。**页面显示不报错 ≠ 代码没问题**。

## 注释

```html
<!-- 这是注释，浏览器会忽略它，但查看源代码的人能看到 -->
```

## 空白折叠

HTML 中连续的空格、换行会被折叠成一个空格：

```html
<p>你好，
      世界</p>
<!-- 显示为：你好， 世界 -->
```

所以你可以放心地用换行和缩进来排版代码，不会影响页面显示。需要真正的空格排版时，交给 CSS 处理，而不是敲一堆 `&nbsp;`。

## 练习

1. 手敲一遍完整的 HTML 骨架（不用 Emmet），直到不看资料也能默写。
2. 把 `<meta charset="UTF-8">` 删掉，在页面里写几句中文，用浏览器打开看看会发生什么。
3. 写一段故意交叉嵌套的代码，在浏览器里右键“检查”，看看浏览器把它修复成了什么样。

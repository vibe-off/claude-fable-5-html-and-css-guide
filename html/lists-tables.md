# 列表与表格

## 无序列表：ul

条目之间没有先后顺序时使用（导航菜单、特性列表）：

```html
<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>
```

## 有序列表：ol

顺序有意义时使用（步骤、排名）：

```html
<ol>
  <li>打开编辑器</li>
  <li>编写代码</li>
  <li>保存并在浏览器中查看</li>
</ol>
```

`<ol>` 支持 `start="5"`（从 5 开始编号）和 `reversed`（倒序）属性。

## 嵌套列表

列表可以嵌套，注意子列表要写在 `<li>` **内部**：

```html
<ul>
  <li>
    前端
    <ul>
      <li>HTML</li>
      <li>CSS</li>
    </ul>
  </li>
  <li>后端</li>
</ul>
```

::: warning
`<ul>` 和 `<ol>` 的直接子元素只能是 `<li>`。把 `<p>` 或 `<div>` 直接放进 `<ul>` 是无效的 HTML。
:::

## 描述列表：dl

“术语—解释”成对出现的场景：

```html
<dl>
  <dt>HTML</dt>
  <dd>负责网页的结构和内容。</dd>
  <dt>CSS</dt>
  <dd>负责网页的样式和布局。</dd>
</dl>
```

## 表格：呈现二维数据

```html
<table>
  <caption>本学期课程表（节选）</caption>
  <thead>
    <tr>
      <th>时间</th>
      <th>周一</th>
      <th>周三</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>上午</td>
      <td>Web 前端开发</td>
      <td>数据库原理</td>
    </tr>
    <tr>
      <td>下午</td>
      <td>体育</td>
      <td>Web 前端开发（实验）</td>
    </tr>
  </tbody>
</table>
```

结构说明：

| 标签 | 含义 |
| --- | --- |
| `<table>` | 表格容器 |
| `<caption>` | 表格标题 |
| `<thead>` / `<tbody>` / `<tfoot>` | 表头 / 表体 / 表尾分组 |
| `<tr>` | 一行（table row） |
| `<th>` | 表头单元格（默认加粗居中，且带语义） |
| `<td>` | 数据单元格（table data） |

### 合并单元格

- `colspan="2"`：横向合并，占两列。
- `rowspan="2"`：纵向合并，占两行。

```html
<tr>
  <th colspan="2">合并了两列的表头</th>
</tr>
```

合并后记得删掉被占位置的多余单元格——这是新手最容易数错的地方，画个草图再写代码。

::: danger 不要用表格做页面布局
在 CSS 布局成熟之前（约 2005 年前），人们曾用 `<table>` 排版整个网页。这种做法早已淘汰：代码臃肿、无法响应式、可访问性差。**表格只用于展示真正的表格数据**（课程表、成绩单、价目表），页面布局用 Flexbox 和 Grid。
:::

## 练习

1. 用有序列表写一份“泡面的正确做法”，其中某一步里再嵌套一个无序列表列出可选配料。
2. 把你自己本学期的课程表做成一个 HTML 表格，至少用到一次 `colspan` 或 `rowspan`。
3. 表格默认没有边框线。先记下这个问题，学完 [CSS 基础](/css/)后回来给它加上边框和隔行变色。

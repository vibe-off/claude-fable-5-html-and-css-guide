# 文本与标题

网页的主体是文本。HTML 提供了一组标签来描述文本的**结构和含义**——注意，是含义，不是样式。

## 标题：h1 到 h6

```html
<h1>一级标题：页面主题</h1>
<h2>二级标题：主要章节</h2>
<h3>三级标题：小节</h3>
<h4>四级标题</h4>
<h5>五级标题</h5>
<h6>六级标题</h6>
```

标题标签表达的是**文档的层级大纲**，就像论文的章节编号。

::: warning 常见误区
不要因为“h3 的字号看起来合适”就用 h3——字号是 CSS 的事。标题层级要像论文目录一样合理：一个页面通常只有一个 `<h1>`；不要跳级（h1 下面直接用 h4）。搜索引擎和读屏软件都依赖标题层级理解你的页面。
:::

## 段落与换行

```html
<p>这是一个段落。段落之间默认有间距。</p>
<p>这是另一个段落。</p>

<p>地址：北京市海淀区<br />某某路 1 号</p>

<hr />
<!-- hr 是主题分隔线，表示内容的转折 -->
```

`<br />` 只用于**内容本身需要换行**的场景（地址、诗歌）。想控制段落间距请用 CSS 的 `margin`，不要连敲好几个 `<br />`。

## 强调与重要

```html
<p>截止时间是<strong>本周五 18:00</strong>，请<em>务必</em>准时提交。</p>
```

- `<strong>`：内容很重要（默认显示为粗体）。
- `<em>`：语气上的强调（默认显示为斜体）。
- `<b>` 和 `<i>` 只表示“粗体”“斜体”的视觉效果，不带语义。现代开发中优先用 `strong` 和 `em`。

## div 与 span：无语义的容器

```html
<div>
  <p>div 是块级容器，独占一行，用来把一组内容打包。</p>
</div>

<p>span 是<span class="highlight">行内容器</span>，用来包住一小段文字以便加样式。</p>
```

它们本身没有任何语义，纯粹为 CSS 和 JavaScript 提供“挂钩”。**能用语义化标签时优先用语义化标签**，详见[语义化 HTML](/html/semantic)。

## 引用与代码

```html
<blockquote>
  <p>任何足够先进的技术都与魔法无异。</p>
</blockquote>

<p>行内代码用 <code>code</code> 标签，比如 <code>console.log()</code>。</p>

<pre><code>// pre 保留空白和换行，适合多行代码
function hello() {
  console.log("Hello");
}</code></pre>
```

## 字符实体

有些字符在 HTML 中有特殊含义，想显示它们本身需要用**字符实体**：

| 想显示 | 写法 | 说明 |
| --- | --- | --- |
| `<` | `&lt;` | less than |
| `>` | `&gt;` | greater than |
| `&` | `&amp;` | ampersand |
| 空格（不折叠） | `&nbsp;` | non-breaking space |
| `"` | `&quot;` | quote |

```html
<p>在 HTML 里，&lt;p&gt; 表示段落标签。</p>
```

## 练习

1. 用标题和段落标签写一份你的“个人简介”页面：姓名用 `h1`，“教育经历”“兴趣爱好”用 `h2`，每个小节写一两个段落。
2. 在简介中用 `strong` 标出你最想让读者注意的一句话。
3. 写一个段落，在页面上显示这行字：`HTML 标签写法是 <标签名>内容</标签名>`（提示：需要字符实体）。

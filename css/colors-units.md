# 颜色与单位

## 表示颜色的几种方式

```css
.demo {
  /* 1. 颜色关键字：适合快速试验 */
  color: tomato;

  /* 2. 十六进制：最常见，#RRGGBB */
  color: #3b82f6;
  color: #fff; /* 三位缩写，等于 #ffffff */

  /* 3. rgb / rgba：a 是透明度 0~1 */
  color: rgb(59, 130, 246);
  background: rgba(0, 0, 0, 0.5); /* 半透明黑，常用于遮罩 */

  /* 4. hsl：色相(0-360) 饱和度 亮度，调色直观 */
  color: hsl(217, 91%, 60%);
}
```

::: tip hsl 的好处
同一色相下调亮度就能得到一组和谐的深浅变化：`hsl(217, 91%, 60%)` 是主色，`hsl(217, 91%, 95%)` 就是同色系的浅背景。设计配色时比十六进制直观得多。
:::

### opacity 与 rgba 的区别

```css
.a {
  background: rgba(255, 0, 0, 0.5); /* 只有背景半透明 */
}
.b {
  background: red;
  opacity: 0.5; /* 整个元素（包括文字、子元素）都半透明 */
}
```

## 长度单位

### 绝对单位：px

`px`（像素）最直观，初学阶段大胆用。边框、阴影、小间距用 px 很合适。

### 相对单位：em 与 rem（重点）

- `em`：相对于**当前元素自身的字号**。
- `rem`：相对于**根元素（html）的字号**，默认 16px。

```css
html {
  font-size: 16px;
}

.card {
  font-size: 20px;
  padding: 1em;    /* = 20px，跟随自身字号 */
  margin: 1rem;    /* = 16px，跟随根字号，稳定可预期 */
}
```

::: warning em 的嵌套陷阱
`em` 用在 `font-size` 上时相对**父元素**字号，嵌套几层后大小会累积放大或缩小，难以推算。所以现代实践是：**间距和字号优先用 rem**，只在“希望跟随组件自身字号缩放”的场景用 em。
:::

用 rem 的实际收益：用户在浏览器设置里调大默认字号（很多中老年用户会这样做），整个页面按比例放大，不会乱。

### 百分比

相对于**父元素**的对应属性：

```css
.child {
  width: 50%; /* 父元素宽度的一半 */
}
```

### 视口单位：vw / vh

相对于浏览器窗口（视口）：`1vw` = 视口宽度的 1%，`1vh` = 视口高度的 1%。

```css
.hero {
  height: 100vh; /* 满屏首屏 */
}
```

## 单位选用速查

| 场景 | 推荐 |
| --- | --- |
| 字号、段落间距 | `rem` |
| 边框、阴影、圆角 | `px` |
| 容器宽度 | `%` + `max-width` |
| 满屏区域 | `vh` / `vw` |
| 行高 | **无单位数字**，如 `line-height: 1.6` |

```css
/* 一个综合示例 */
.container {
  width: 90%;
  max-width: 1200px; /* 最宽 1200px，小屏幕自动收缩 */
  margin: 0 auto;    /* 水平居中 */
}
body {
  font-size: 1rem;
  line-height: 1.6;  /* 1.6 倍自身字号，无单位写法可被子元素正确继承 */
}
```

## 练习

1. 用 hsl 选一个主色，做出它的深色版（亮度调低）和浅色背景版（亮度调高），应用到一个按钮的默认、悬停、禁用三种状态。
2. 把 `html { font-size: 20px; }` 加到页面上，观察用 rem 的间距如何整体变化，而用 px 的部分纹丝不动。
3. 做一个 `height: 100vh` 的首屏区域，里面放标题和一句介绍；缩放浏览器窗口观察它的行为。

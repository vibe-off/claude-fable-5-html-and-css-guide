# Text & Fonts

90% of web content is text. Get the typography right and a page instantly looks professional.

## Font families: font-family

```css
body {
  font-family: system-ui, -apple-system, "Segoe UI", Roboto, sans-serif;
}
```

The browser tries the list **left to right** and uses the first font installed on the user's machine — hence the name **font stack**. Always end with a generic family as the safety net:

- `sans-serif`: clean and modern — the default choice for interfaces
- `serif`: for long-form reading
- `monospace`: for code

::: tip A note on CJK fonts
Chinese/Japanese/Korean font files are huge (often several MB), so sites usually rely on system fonts rather than downloading them — e.g. `"PingFang SC"` on macOS, `"Microsoft YaHei"` on Windows for Simplified Chinese. If your audience reads CJK languages, add those names before the generic fallback.
:::

## Size, weight, and style

```css
h1 {
  font-size: 2rem;      /* size */
  font-weight: 700;     /* weight: 400 normal, 700 bold — bigger is heavier */
}
em {
  font-style: italic;
}
```

## Line height: line-height

Line height affects readability more than almost any other property:

```css
body {
  line-height: 1.6; /* body text: 1.5–1.8 recommended */
}
h1 {
  line-height: 1.2; /* headings can be tighter */
}
```

::: tip The old single-line centering trick
Set `line-height` equal to the container's `height` and a single line of text centers vertically. The modern, general answer is Flexbox — see [Flexbox](/en/concepts/flexbox).
:::

## Text layout properties

```css
.article {
  text-align: left;          /* left / center / right / justify */
  text-indent: 2em;          /* first-line indent (em fits naturally here) */
  letter-spacing: 0.05em;    /* tracking */
  text-decoration: none;     /* commonly used to strip link underlines */
  text-transform: uppercase; /* capitalize English text */
}
```

## Common text effects

### Text shadow

```css
.title {
  text-shadow: 2px 2px 4px rgba(0, 0, 0, 0.3);
  /*           x     y    blur  color */
}
```

### Single-line ellipsis

A high-frequency real-world need (list titles, card summaries):

```css
.ellipsis {
  white-space: nowrap;     /* don't wrap */
  overflow: hidden;        /* clip overflow */
  text-overflow: ellipsis; /* show … */
}
```

All three lines are required — worth memorizing. Multi-line clamping is covered in [Modern CSS](/en/advanced/modern-css).

## Web fonts: @font-face

When you need a specific typeface (headings, logos), have the user download it:

```css
@font-face {
  font-family: "MyFont";
  src: url("./fonts/myfont.woff2") format("woff2");
  font-display: swap; /* show a system font while loading, avoiding invisible text */
}

h1 {
  font-family: "MyFont", sans-serif;
}
```

Or use the `<link>` snippet generated by services like Google Fonts. Mind licensing: commercial projects must verify the font's license.

## A body-text setup you can copy

```css
body {
  font-family: system-ui, -apple-system, "Segoe UI", Roboto, sans-serif;
  font-size: 1rem;
  line-height: 1.7;
  color: #333;
}
h1, h2, h3 {
  line-height: 1.3;
  color: #111;
}
a {
  color: #2563eb;
  text-decoration: none;
}
a:hover {
  text-decoration: underline;
}
```

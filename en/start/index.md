# How to Use This Guide

Welcome! This is an **HTML & CSS starter course for college students**. By the end, you will be able to build static web pages that are well-structured, good-looking, and work on both phones and desktops — the foundation for learning JavaScript and Vue afterwards.

## How the guide is organized

| Part | Content | Goal |
| --- | --- | --- |
| Part 1 · HTML Fundamentals | Tags, text, links, images, tables, forms, semantics | Describe content with the right structure |
| Part 2 · CSS Fundamentals | Syntax, selectors, colors, units, fonts | Add style to your pages |
| Part 3 · Key Concepts | Box model, cascade, positioning, Flexbox, Grid, responsive | Truly *understand* layout instead of guessing |
| Part 4 · Extended Topics | Variables, animations, modern CSS, naming, debugging, AI collaboration | Work the way professionals do |

Parts 1–2 are your "vocabulary", Part 3 is the "grammar", Part 4 is "writing style". **Part 3 (Key Concepts) is what interviews and real projects test the most** — it is also where self-taught learners tend to be weakest. Invest the most time there.

## How to learn effectively

1. **Type every code sample yourself.** You cannot learn frontend by copy-pasting. Typing exposes the things you thought you understood but didn't.
2. **Break the code on purpose.** Delete a closing tag, change `flex` to `block`, and watch what happens. Understanding *why it breaks* teaches more than memorizing what is correct.
3. **Do the exercises at the end of each section.** They are small, but skipping them means you didn't really learn.
4. **Use AI well, but don't let it think for you.** Asking AI to explain concepts, review your code, or quiz you is great; having it generate your homework and submitting it as-is will catch up with you in practical exams and interviews. See [Learning Frontend with AI](/en/advanced/ai).

::: tip An honest reminder
AI can already write decent front-end code. But companies hire you to **take responsibility for code**: changing requirements, fixing bugs, explaining why it is written this way. All of that rests on fundamentals. Fundamentals are not the part AI replaces — they are your leverage for using AI.
:::

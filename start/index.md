# 导读：如何使用本指南

欢迎！这是一份面向大学生的 **HTML 与 CSS 入门讲义**。学完它，你将能够独立写出结构清晰、样式美观、适配手机和电脑的静态网页——这是后续学习 JavaScript 和 Vue 的地基。

## 这份指南的结构

| 部分 | 内容 | 目标 |
| --- | --- | --- |
| 第一部分 · HTML 基础 | 标签、文本、链接、图片、表格、表单、语义化 | 用正确的结构描述内容 |
| 第二部分 · CSS 基础 | 语法、选择器、颜色、单位、字体 | 给网页加上样式 |
| 第三部分 · 核心概念 | 盒模型、层叠、定位、Flexbox、Grid、响应式 | 真正“理解”布局，而不是碰运气 |
| 第四部分 · 拓展主题 | 变量、动画、现代 CSS、命名规范、调试、AI 协作 | 接近真实工作的方式 |

前两部分是“词汇”，第三部分是“语法”，第四部分是“写作技巧”。**第三部分（核心概念）是面试和实战中最常被考察的内容**，也是很多自学者的薄弱环节，请务必投入最多时间。

## 怎样学才有效

1. **每一段代码都亲手敲一遍。** 复制粘贴学不会前端。手敲会暴露你以为自己懂了、其实没懂的地方。
2. **主动把代码改坏。** 删掉一个闭合标签、把 `flex` 改成 `block`，观察页面发生了什么。理解“为什么会坏”比记住“怎样是对的”更重要。
3. **完成每节末尾的练习。** 练习都很小，但不做等于没学。
4. **善用 AI，但别让它替你思考。** 让 AI 解释概念、检查代码、出题考你，都很好；直接让它生成作业然后原样上交，你会在上机考核和面试中原形毕露。详见[与 AI 一起学前端](/advanced/ai)。

::: tip 一个诚实的提醒
AI 已经能写出不错的前端代码，但公司雇你，是要你**对代码负责**：改需求、修 Bug、解释为什么这样写。这些能力全部建立在基础之上。基础不是被 AI 淘汰的部分，而是你使用 AI 的杠杆。
:::
